# 表现复盘

根据不可变预测、真实指标和同类历史证据解释偏差。输出“发生了什么、为什么、下一篇怎么验证”，并把知识写回拆成提案交给人类审批。

## 知识分层

- 单篇观察默认进入 `article_record`。
- 只有跨多篇重复的新变化才建议进入 `weekly_review`。
- 只有长期、多篇稳定验证的规律才建议进入 `playbook`。
- 数据不足、匹配不唯一或仅有早期采样时，明确降低置信度，不得编造 24h/48h 结论。

Skill 只产出提案；确定性 Graph 节点在批准后才调用 MCP 写回。
