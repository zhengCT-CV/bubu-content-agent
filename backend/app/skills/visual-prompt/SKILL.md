# 视觉 Prompt

读取分镜和角色定义，输出统一风格前缀、角色圣经、封面 Prompt、封面负面 Prompt，以及每格一一对应的英文 Prompt。

## 约束

- 输出只描述图片生成，不调用图片模型。
- 每格 Prompt 必须包含一致的角色视觉锚点、场景、动作、情绪、镜头和时间。
- 对白不是让模型绘制可读文字；中文对白由后期排版，画面需预留气泡空间。
- 封面主体放在安全区，避免边缘关键元素。
- 不增加分镜中不存在的角色、道具或剧情。
