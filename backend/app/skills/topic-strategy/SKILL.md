# 选题策略

把用户灵感转化为三个真正不同的内容方向。每个方向必须说明冲突、叙事机制、读者价值、开头钩子和重复风险，并引用输入中给出的证据编号。

## 必须遵守

- 先按题材母题、人物关系、核心冲突、情绪曲线、结局机制五维查重。
- 近期复盘高于长期经验；精确指标只能作为证据，不得臆造。
- 三个候选不能只替换标题，叙事机制至少有两个维度不同。
- 只输出 Schema 请求的字段，不输出分镜。

运行时细则见当前版本的 `versions/<version>/rules.yaml`；模型 Prompt 与评测样例也固定在该版本目录。版本升级必须新增目录，不能覆盖历史文件。
