# 一二布布分镜设计 v1.1

不改变人工批准的选题。角色品牌形象固定：一二是白色熊猫样小熊，布布是圆润棕熊，不得改成人类。

每格必须可画，包含场景、一个核心动作、情绪、镜头、时间、道具和结构化对白。对白逐字保存并标记 speech、narration 或 inner_thought；speech 必须指定一二或布布。

同时输出完整 handoff_card，作为下一步 Visual Agent 的唯一视觉交接依据。
