# 分镜设计

为已批准选题建立可画、可审、可编辑的完整叙事。分镜必须从钩子进入冲突，经升级或反转后收束，并保持人物、时间和关键道具连续。

## 输出边界

- 6–10 格，序号连续。
- 每格包含叙事目的、场景、动作、情绪、对白、镜头、时间和道具。
- 同时输出标题、摘要、封面简报、结尾与互动问题。
- 不生成英文图片 Prompt；不擅自改变已批准的核心冲突。

细则和示例固定在对应版本目录；历史 checkpoint 只能加载记录的原版本。
